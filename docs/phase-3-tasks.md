# Phase 3 — UI (revised 2026-10-26 after the owner's decisions D-42..D-47; built 2026-10-26)

Drafted at the Phase 2 gate, then revised before any Phase 3 code was written, to fold in the owner's decisions of 2026-10-26 (`docs/decisions.md` D-42..D-47). Phase 3 adds pages and server actions over the Phase 2 write path; the engines and the replay do not change. Every page reads balances by summing `LedgerEntry` (non-negotiable 1) and request state from the last `RequestEvent` — nothing is cached.

**What changed from the draft:** 3.0 is no longer a decision to take — the owner took it (D-42 `Employee.userId` set by an audited HR action, D-43 org IANA zone with one converter) and it is built with D-44..D-47 before 3.1. The HR console gains the people/link screen (D-42), the zone setting (D-43) and archive (D-47). The submit form shows an overlapping request before submit (D-45). The nightly close skips archived orgs (D-47). Billing is gone (D-46), so no billing link anywhere. The `/demo` question is settled as a separate hand-org seed, not the fixture org (below, 3.7).

Exit bar: the hand org's GR-15 can be walked in a browser (approve, void approval shown as void with its code, reassign, approve) with Playwright + axe green in both colour schemes; every number on a screen is produced by a Phase 2 function with a test; the scope banner (README text, verbatim) is on every page that shows a number the product claims and the D-26 sick-policy sentence is verbatim where the policy is shown; no float, no `Date` on a day path, nothing sent.
